Build a brand new test application called "BrightBridge EasyTeam Integration Test" to test and explore the EasyTeam Embedded SDK. This is a sandbox testing app to understand how EasyTeam components work before integrating them into the main platform.

IMPORTANT — API KEY SETUP:
Before building anything
ask me for the following:

1. EasyTeam Sandbox API Key
   Say to user:
   "Please provide your 
   EasyTeam Sandbox API Key
   so I can set it up securely
   as an environment variable"

2. Once user provides the key:
   Store it as environment variable:
   EASYTEAM_API_KEY=provided_key
   
   Never hardcode the key
   in any file!
   Always use:
   process.env.EASYTEAM_API_KEY

STEP 2 — BACKEND SETUP:
Create a Node.js Express backend
with these endpoints:

ENDPOINT 1 — Generate Token:
POST /api/easyteam/token

This endpoint:
→ Takes employee/user details
→ Calls EasyTeam API to get
  an authentication token
→ Returns token to frontend

Code:
const response = await axios.post(
  'https://api.easyteam.com/v1/auth/token',
  {
    api_key: process.env.EASYTEAM_API_KEY,
    employee_id: req.body.employee_id,
    company_id: req.body.company_id
  }
);
return response.data.token;

ENDPOINT 2 — Get Employees:
GET /api/easyteam/employees

Returns list of all employees
from EasyTeam sandbox

ENDPOINT 3 — Get Timesheets:
GET /api/easyteam/timesheets

Returns timesheet data
from EasyTeam sandbox

ENDPOINT 4 — Webhook Receiver:
POST /api/easyteam/webhook

Receives automatic notifications
from EasyTeam when:
→ Employee clocks in
→ Employee clocks out
→ Timesheet updated
→ Log all received webhooks

EASYTEAM INITIALIZATION CODE:
In your React app
initialize EasyTeam like this:

import { EasyTeamProvider } from '@easyteam/react';

function App() {
  return (
    <EasyTeamProvider
      apiKey={process.env.REACT_APP_EASYTEAM_API_KEY}
      environment="sandbox"
      theme={{
        primaryColor: '#1B3A6B',
        accentColor: '#0EA5C9',
        fontFamily: 'Inter, sans-serif'
      }}
    >
      {/* Your app components */}
    </EasyTeamProvider>
  );
}

This sets up:
→ API connection
→ Sandbox environment
→ BrightBridge colors
→ Available everywhere in app
