THE PROBLEM I AM SOLVING:
We are about to switch this app from 
Rollfi sandbox credentials to Rollfi 
production credentials (real payroll, 
real money). I need to be able to 
switch between the two environments 
safely and reversibly, without ever 
losing the sandbox credentials or 
accidentally believing I am in sandbox 
when I am actually live.

THE APPROACH I AM CONSIDERING:

Instead of overwriting a single set of 
credential environment variables each 
time I switch, store BOTH sets 
permanently and use one switch 
variable:

ROLLFI_ENV                 = "sandbox" 
                             or 
                             "production"
ROLLFI_SANDBOX_API_URL
ROLLFI_SANDBOX_CLIENT_ID
ROLLFI_SANDBOX_SECRET_KEY
ROLLFI_PROD_API_URL
ROLLFI_PROD_CLIENT_ID
ROLLFI_PROD_SECRET_KEY

A single config module would resolve 
which set to use based on ROLLFI_ENV, 
and every part of the codebase that 
currently reads Rollfi credentials 
would import from that module instead. 
Switching environments would then mean 
changing one value and restarting.

Additional intent: a UI banner that 
reads the active environment (red 
"PRODUCTION" vs the current blue 
"SANDBOX") so the interface can never 
disagree with the credentials actually 
in use, plus extra confirmation dialogs 
in production before running payroll, 
creating a company, or terminating an 
employee.
