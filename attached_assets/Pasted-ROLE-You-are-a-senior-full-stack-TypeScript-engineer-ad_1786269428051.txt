CONTEXT — VERIFIED FROM ROLLFI DOCS 
(CompanyBankAccountLinking):
Plaid requires NO separate endpoint — it 
is the same addCompanyBankAccount call 
with extra fields:

- linkType: "Manual" | "Plaid" | 
  "CustomProvider"
- When linkType is "Plaid", set 
  plaidOptions to either:
  * "generateURL" → the response 
    contains plaidLinkURL to surface in 
    our own UI
  * "sendInviteByEmail" → Rollfi emails 
    a one-time Plaid link to the payroll 
    admin; optional "email" field 
    overrides the destination
- Plaid links expire after roughly 72 
  hours; the valid link is reused for 
  subsequent addCompanyBankAccount calls 
  until it expires

For the URL flow the request looks like:
{ "method": "addCompanyBankAccount",
  "linkType": "Plaid",
  "plaidOptions": "generateURL",
  "companyFundingSourceEntity": { 
    "companyId": "..." } }

Note that with Plaid, no account/routing 
numbers are submitted by us — the user 
authenticates with their bank directly.

PART 1 — BACKEND

Extend POST /rollfi/onboard/bank-account 
to accept:
- linkType: "Manual" (default, existing 
  behaviour) or "Plaid"
- plaidOptions: "generateURL" or 
  "sendInviteByEmail" (required when 
  linkType is "Plaid")
- email (optional, only for 
  sendInviteByEmail)

Behaviour:
- linkType "Manual": unchanged — 
  existing validation and submission 
  path, including the required 
  accountName.
- linkType "Plaid" + "generateURL": 
  call addCompanyBankAccount with only 
  companyId in companyFundingSourceEntity 
  (no account/routing/accountName), and 
  return { plaidLinkURL, expiresNote } 
  to the client.
- linkType "Plaid" + "sendInviteByEmail": 
  same call with plaidOptions 
  sendInviteByEmail (plus email when 
  provided); return a confirmation state 
  — no URL is returned by Rollfi in this 
  flow.
- Store on the company record which link 
  method was used and, for Plaid, when 
  the link was generated (so we can show 
  expiry and offer regeneration).
- Never log the plaidLinkURL in full.

Also ensure the existing bank-status 
helper (normalised: status, verified, 
last4, bankName, accountType) is used to 
detect completion for Plaid-linked 
accounts — Plaid completion is confirmed 
by the funding source appearing/verified 
in Rollfi, not by our own state.
