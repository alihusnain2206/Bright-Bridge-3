artifacts/api-server/src/routes/rollfi.ts has
no router-level auth middleware. Specifically
GET /rollfi/payroll/preview has no session
check in its handler, and uses the pattern
`!companyId || u.companyId === companyId` —
so an absent companyId skips the filter and
returns all staff across all companies with
wages, approved hours, and pay amounts.

This file drives real payroll and real bank
debits. We will fix it surgically. This audit
tells us exactly what is safe to touch.
