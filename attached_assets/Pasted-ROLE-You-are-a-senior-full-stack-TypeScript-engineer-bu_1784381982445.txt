PART 6 — DATA FETCHING RULES

1. ONE primary fetch per company 
   selection: the employee list 
   (with all fields needed for the 
   table already on the employee 
   record — displayId, department, 
   managerName, complianceScore, 
   status are all stored fields)

2. Departments fetched once per 
   company for the filter dropdown

3. Compliance item DETAILS fetched 
   on demand only (when popover 
   opened) — NOT for every row 
   upfront

4. No duplicate calls — single 
   useEffect keyed on companyId, 
   following the same pattern we 
   fixed on the payroll page

5. No cross-company requests — 
   only the selected company's data

6. If complianceScore is null/
   undefined on an employee 
   (older records), display "—" 
   in the compliance column rather 
   than 0 or NaN
