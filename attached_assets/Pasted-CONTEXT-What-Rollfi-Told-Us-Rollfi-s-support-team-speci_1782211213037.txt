CHANGE 4 — Pull REAL Tax Data from Rollfi:
After payroll is SUBMITTED,
call getPayPeriodDetails to get
REAL tax amounts from Rollfi:

Add new backend endpoint:
GET /api/rollfi/payperiod/details

Code:
router.get('/rollfi/payperiod/details', 
async (req, res) => {
  const { companyId, payPeriodId } = req.query;
  const rollfiCompany = store.getRollfiCompany(companyId);
  
  try {
    const response = await axios.post(
      `${ROLLFI_BASE_URL}/reports#getPayPeriodDetails`,
      {
        method: 'getPayPeriodDetails',
        companyId: rollfiCompany.rollfiCompanyId,
        payPeriodId
      },
      { headers: rollfiHeaders() }
    );
    
    req.log.info(
      { rollfiResponse: response.data },
      'getPayPeriodDetails response'
    );
    
    res.json(response.data);
  } catch (err) {
    req.log.error({ err }, 
      'getPayPeriodDetails failed');
    res.status(500).json({ 
      error: 'Failed to get pay period details' 
    });
  }
});

Extract these fields from response:
→ Per employee:
   employeeId

   };
   
   NOTE: These are ESTIMATES only!
   Real amounts come from Rollfi!
   Different for each employee
   based on their W4 settings!

2. ALWAYS LABEL ESTIMATES:
   Never show estimated tax amounts
   WITHOUT the "est." or "~" label
   Real amounts only after Rollfi
   confirms via getPayPeriodDetails

3. REAL DATA PRIORITY:
   If getPayPeriodDetails returns
   real tax amounts from Rollfi:
   → Use Rollfi amounts (more accurate)
   → Remove "est." labels
   → Show "Confirmed by Rollfi ✅"
   
   If getPayPeriodDetails fails or
   payroll not yet submitted:
   → Use estimated amounts
   → Always show "est." label
   → Never present estimates as real!

4. NET PAY FORMULA (estimate):
   netPay = grossPay - 
   (grossPay × 0.12) -  // federal
   (grossPay × 0.05) -  // NJ state
   (grossPay × 0.062) - // SS
   (grossPay × 0.0145)  // Medicare
   = grossPay × 0.7535

5. DEBIT AMOUNT FORMULA (estimate):
   debitAmount = grossPay +
   (grossPay × 0.062) +  // employer SS
   (grossPay × 0.0145) + // employer Medicare
   (grossPay × 0.006) +  // FUTA
   (grossPay × 0.005)    // NJ SUTA
   = grossPay × 1.0875
