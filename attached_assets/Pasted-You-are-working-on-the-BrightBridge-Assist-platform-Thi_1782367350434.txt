PART 11 — IMPORTANT TECHNICAL RULES

These rules must be followed
throughout all TypeScript code:

WAGES — ALWAYS dollars in UI:
// Display to user:
const displayWage = employee.hourlyWage / 100;
// "$18.00/hr"

// Send to Rollfi:
const rollfiWage = Math.round(
  displayWage * 100
);
// 1800

// Store in database:
// Always store as cents (1800)
// Never store as dollars for wages

NEVER hardcode:
→ Company names
→ Employee names  
→ Emails or passwords
→ Rollfi IDs
→ EasyTeam IDs
All data comes from JSON files
or the Rollfi/EasyTeam APIs!

ALWAYS check authentication:
Every API endpoint must check
req.session.userId exists
Return 401 if not authenticated

ALWAYS handle errors gracefully:
Every API call wrapped in try/catch
Always show user-friendly error message
Never show raw error objects to users
Always log errors with req.log.error

FORM VALIDATION:
All required fields validated
before API calls are made
Show inline validation errors
Never submit incomplete forms

LOADING STATES:
Show loading spinner/overlay
for all API operations
Disable submit buttons while loading
Never allow double-submission

SANDBOX WARNING:
Keep the existing yellow sandbox
banner at the top of every page
