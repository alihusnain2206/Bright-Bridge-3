PART 3 — THE TABS

TAB 1 — OVERVIEW (new, default):
Two-column snapshot grid:
→ Key Info card: email, phone, 
  start date + tenure, employment 
  type, worker type, work location, 
  department, manager
→ Compliance summary card: score 
  ring + "X of Y required complete" 
  + top 3 outstanding items, 
  "View all →" switches to 
  compliance tab
→ Onboarding summary card (hide 
  when 100%): progress bar + next 
  3 pending required tasks with 
  due dates, "View all →" → 
  onboarding tab
→ Recent Activity card: last 5 
  entries for this employee, 
  "View all →" → activity tab

TAB 2 — JOB & PAY (new):
→ Position card: job title, 
  department, manager, employment 
  type, worker type, start date, 
  work location
→ Compensation card: pay type, 
  wage (from employee record; 
  format $X.XX/hr or salary), 
  overtime eligible, payment 
  method. Data note chip "Synced 
  with Rollfi" when rollfiWageId 
  exists
→ System card: employee display 
  ID, internal ID, Rollfi status 
  (kycStatus, rollfiUserId 
  present?), EasyTeam sync status 
  — read-only diagnostics

TAB 3 — ONBOARDING:
Render the EXISTING task list 
content (summary cards + staged 
task list + TaskActionModal) as a 
component embedded in the tab. 
Extract the current tasks page 
body into a shared component 
(EmployeeTasksPanel) if not 
already one, and use it in BOTH 
the old route (until redirect) 
and this tab. All behavior 
identical (complete, reopen, 
notes, review mode).

TAB 4 — COMPLIANCE:
Same approach: extract compliance 
page body into 
EmployeeCompliancePanel and embed. 
Smart routing (Complete via Task /

works identically inside the tab.

TAB 5 — DOCUMENTS:
Embed existing EmployeeDocuments 
component.

TAB 6 — EMERGENCY CONTACTS:
Embed existing contacts list + 
EmergencyContactForm (add/edit/
delete).

TAB 7 — PAYROLL (new, read-only):
→ If no rollfiUserId: empty state 
  "Payroll setup incomplete"
→ Else: paystub list for this 
  employee across processed 
  periods — reuse the existing 
  paystubs endpoint 
  (/rollfi/paystubs) filtered to

  taxes, net, with expandable

  paystub rendering. If per-
  employee filtering needs a
