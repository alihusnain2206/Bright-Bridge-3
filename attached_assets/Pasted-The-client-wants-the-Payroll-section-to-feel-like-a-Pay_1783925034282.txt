The client wants the Payroll section 
to feel like a "Payroll Operations 
Command Center" — not a simple 
payroll list. The client is competing 
with ADP, Paychex, Rippling, and 
Gusto so the design needs to feel 
professional and data-rich.

We already have these backend 
endpoints working that provide 
ALL the data needed:

GET /rollfi/payperiod?companyId=xxx
→ Returns current unprocessed period

GET /rollfi/payperiod/history?companyId=xxx
→ Returns processed past periods

GET /rollfi/payperiod/details?companyId=xxx&payPeriodId=xxx
→ Returns FULL pay period details:
   total (bank debit), employeeTaxSum,
   employerTaxSum, isProcessed,
   payrollLineItems per employee with
   employeeTaxDetails, employerTaxDetails,
   netTotal, grossTotal, overTimes,
   deductions, reimbursements, payDetails

GET /rollfi/payroll/preview?companyId=xxx
→ Returns employee hours and pay preview

GET /rollfi/payroll/overview
→ Returns all companies payroll summary

POST /rollfi/payroll/initiate
→ Submits payroll to Rollfi

GET /rollfi/paystubs?companyId=xxx&payPeriodId=xxx
→ Returns per employee paystub data

GET /rollfi/company-tasks?companyId=xxx
→ Returns onboarding/compliance tasks

GET /rollfi/employees/status?companyId=xxx
→ Returns employee Rollfi activation status

All data is available. This task is 
about DISPLAYING it professionally.
