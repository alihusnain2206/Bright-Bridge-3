WIDGET 2 — PAYROLL VARIANCE

PURPOSE:
Compare the current payroll period 
to the previous completed period 
and highlight what changed and why, 
so managers can catch errors or 
understand cost changes before 
approving payroll.

DATA SOURCE:
1. Current period data from:
   GET /rollfi/payperiod/details
   → total, employeeTaxSum, 
   employerTaxSum, payrollLineItems

2. Last completed period from:
   GET /rollfi/payperiod/history
   → Get most recent processed period
   → Then call details for that 
   period too

3. Calculate variance:
   const currentTotal = currentPeriod.total;
   const lastTotal = lastPeriod.total;
   const varianceAmount = 
     currentTotal - lastTotal;
   const variancePercent = 
     ((varianceAmount) / lastTotal) * 100;

4. Calculate top variance drivers 
   by comparing per-employee data:
   
   For each employee in current period:
   → Find same employee in last period
     (match by userId)
   → Compare grossTotal
   → If difference > 0: categorize why
   
   Categories:
   → Overtime: sum of overTimes 
     difference between periods
   → New Hires: employees in current 
     but NOT in last period
   → Rate Changes: same employee 
     different payRate
   → Other: remaining difference

DISPLAY:
Title: "Payroll Variance"
Subtitle: "(vs Last Pay Period)"

Show large number:
"8.3%" with up/down arrow
Green if decrease, Red if increase

Show dollar amount:
"$12,345.25 Change in Cash Required"

Show horizontal bar chart of 
top variance drivers:
Overtime     ████████  +$6,234
New Hires    ██████    +$3,215
Rate Changes █████     +$2,145
Bonuses      ████      +$1,120
Other        █         -$370

Each bar colored:
Red/amber for increases
Green for decreases

Link: "View full variance report →"

If no history available:
Show: "Variance available after 
first completed payroll"

If current period not yet calculated:
Show: "Submit payroll to see 
variance analysis"
