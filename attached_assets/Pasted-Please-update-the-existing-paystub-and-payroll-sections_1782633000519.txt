FIX 1 — ADD EMPLOYER TAX SECTION 
TO PAYSTUB:

Find the existing paystub component 
or page in the codebase.

The paystub currently shows:
→ Gross Pay
→ Employee deductions (federal, state,
  SS, Medicare)
→ Net Pay

ADD a new section BELOW the existing 
deductions section called:
"Employer Contributions"

This section shows what the COMPANY 
pays on top of the employee salary.
It is NOT deducted from the employee.

Use these fixed tax rates:
const EMPLOYER_RATES = {
  socialSecurity: 0.062,    // 6.2%
  medicare: 0.0145,         // 1.45%
  futa: 0.006,              // 0.6%
  njSuta: 0.005             // 0.5% NJ
};

Calculate from gross pay:
const grossPay = employee.grossPay;

const employerSS = 
  Math.round(grossPay * 0.062 * 100) / 100;

const employerMedicare = 
  Math.round(grossPay * 0.0145 * 100) / 100;

const futa = 
  Math.round(grossPay * 0.006 * 100) / 100;

const njSuta = 
  Math.round(grossPay * 0.005 * 100) / 100;

const totalEmployerContributions = 
  Math.round(
    (employerSS + employerMedicare + 
     futa + njSuta) * 100
  ) / 100;
